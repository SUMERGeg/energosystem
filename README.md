# ЭнергоСистем — прототип главной

Адаптивный HTML-прототип главной страницы электромонтажной компании. Откройте `index.html` в браузере; установка и сборка не нужны.

В проекте: `index.html`, `styles.css`, `app.js`, изображения и шрифты в `assets/`. Материалы об источниках и дизайне находятся в `source-data/` и `DESIGN.md`.

Форма готовит письмо в почтовом приложении, автоматическая отправка не подключена. Статус проекта за 2020–2021 годы требует подтверждения у компании.
